# Evals

Test cases used to validate this skill during development (see [`objection-sparring-partner`'s Testing section](../../objection-sparring-partner/README.md#testing) for the results). Not required to use the skill — this folder is for maintainers/contributors iterating on `SKILL.md`, safe to ignore or delete if you only installed the skill to use it.

See `evals.json` for the scenario definitions and expected assertions. This tool's core behavior is an interactive roleplay rather than single-shot document generation, so the eval methodology (self-play transcripts, graded per-assertion) differs from `enterprise-account-planner`'s — disclosed in full in `objection-sparring-partner`'s README Testing section.
