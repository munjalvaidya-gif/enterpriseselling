# Battlecard Output Template

Follow this structure exactly for every battlecard produced in Step 2.

```markdown
# Objection Battlecard — <Company Name>

**Selling:** <product/solution>
**Persona:** <the specific stakeholder this battlecard is built against>
**Deal stage:** <discovery / evaluation / negotiation / procurement>
**Prepared:** <date>

## Deal snapshot

- **Account:** <one or two lines on the account/profile as given>
- **MEDDPICC state going in:**
  - Economic Buyer: <confirmed: [name/role] | assumed: [reasoning] >
  - Champion: <confirmed | assumed | none identified>
  - Competition: <confirmed: [who] | assumed: [reasoning] | unknown>
  - (Only call out the elements actually discussed in Step 1 plus anything assumed by stage default — don't fabricate detail on the other five if nothing is known yet.)

## Anticipated objections

For each objection (6-10 total, selected for this specific account/persona/stage — not the full bank):

### "<the objection, in the persona's likely words>"

- **What it's really testing:** <MEDDPICC element, one line on why>
- **The trap:** <what a seller instinctively says that sounds fine but loses ground>
- **Recommended move:** <Force Management technique name> — <one concrete example line the seller could actually say, specific to this account/product>

(Repeat for each objection.)

## Ready to roleplay?

One line inviting the seller into Step 3's live session against this battlecard, or offering to regenerate for a different persona/stage on the same deal.
```

Notes on filling this in:
- Every "recommended move" example line must reference something specific from the account/product context given — a generic line that could apply to any deal is a sign the objection wasn't actually tailored.
- If fewer than 6 objections are genuinely plausible for this account/persona/stage combination, it's fine to ship fewer — don't pad with irrelevant ones just to hit a count.
- Order objections roughly in the sequence they'd likely surface in a real conversation (easier/rapport-testing first, harder/deal-threatening later), not by MEDDPICC letter order.
