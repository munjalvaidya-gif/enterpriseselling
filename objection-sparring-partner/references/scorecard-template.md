# Scorecard Output Template

Follow this structure exactly for every debrief produced in Step 4. Everything in it must be grounded in the actual transcript just played — quote real lines, don't generate generic sales coaching.

```markdown
# Objection Sparring Scorecard — <Company Name>

**Persona faced:** <stakeholder>
**Deal stage:** <stage>
**Session date:** <date>

## What worked

- <Specific moment, quoted or closely paraphrased> — <which Force Management technique this demonstrated and why it landed>
(1-4 entries; if genuinely nothing worked well, say so plainly rather than inventing praise.)

## What to improve

- <Specific moment, quoted or closely paraphrased> — <what was said> → <what a stronger response would have been, concretely, not "be more confident">
(1-4 entries.)

## MEDDPICC scorecard

| Element | This session... | Notes |
|---|---|---|
| Metrics | Advanced / Left open / Exposed a problem | <one line grounded in the transcript> |
| Economic Buyer | ... | ... |
| Decision Criteria | ... | ... |
| Decision Process | ... | ... |
| Paper Process | ... | ... |
| Identify Pain | ... | ... |
| Champion | ... | ... |
| Competition | ... | ... |

(Only mark "Advanced" or "Exposed a problem" where the transcript actually shows it — most sessions won't touch all eight; "Left open" is the honest default for elements the conversation didn't reach.)

## Force Management technique usage

- **Command of the Message:** <instance(s) used well, or explicit note if never attempted>
- **Negative reverse selling:** <instance(s), or note if an opening was offered and missed>
- **Compelling event / cost of inaction:** <instance(s), or note if the case stayed generic>

## Toughest objection this session

<Which one, and whether it was ultimately resolved — if not, name what's still unresolved and needs a real answer before the actual call.>

## Suggested next-step talk track

<1-3 sentences the seller could actually use to open or follow up on the real call, informed by what this session exposed.>
```

Notes on filling this in:
- If the seller ended the session early or it was very short, say so and scope the scorecard honestly to what was actually covered rather than padding out all eight MEDDPICC rows with speculation.
- Never soften "Exposed a problem" into "Left open" to avoid a hard truth — the scorecard's entire value is honesty the seller won't get from a real prospect who just walks away instead of explaining why.
